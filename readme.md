# 🧠 Проект: Digital Double (Цифровой Двойник)

Этот проект предназначен для создания персональной языковой модели на базе архитектур Google Gemma. Мы обучили нейросеть имитировать твой стиль общения, используя методы низкоранговой адаптации (QLoRA).

## 📂 Структура проекта

* **`gemma_fix_env/`** — Виртуальное окружение Python. Содержит все установленные библиотеки (torch, transformers, peft). Всегда работай внутри него.
* **`dataset.jsonl`** — Твой «золотой фонд». Файл с данными для обучения в формате JSON Lines. Содержит пары "instruction" (вопрос) и "output" (твой ответ).
* **`train.py`** — Основной скрипт обучения. Здесь настраиваются параметры модели, квантование (4-bit) и процесс тренировки.
* **`chat.py`** — Скрипт для тестирования и общения с уже обученной моделью.
* **`my_digital_double_model/`** — Папка с результатами обучения Gemma 2. Здесь лежат адаптеры (`adapter_model.safetensors`), которые превращают обычную модель в твоего двойника.
* **`my_digital_double_v3/`** — (Будущая) папка для весов Gemma 3 4B.

## 🛠 Техническое описание проделанной работы

### 1. Подготовка данных

Мы преобразовали историю твоих переписок в формат, понятный для Gemma. Каждое сообщение обернуто в специальные токены:

* `<start_of_turn>user` — вопрос собеседника.
* `<start_of_turn>model` — твой ответ, на котором модель учится.

### 2. Решение проблем совместимости (Gemma 3)

Gemma 3 физически требует **PyTorch 2.6** для работы новых функций маскирования. Поскольку на Windows доступна версия **2.5.1**, мы применили обходной путь:

* Использование `attn_implementation="eager"` для отключения несовместимых оптимизаций.
* Принудительная передача `token_type_ids`, так как без них Gemma 3 выдает ошибку в процессе обучения.

### 3. Оптимизация под RTX 2080 Ti

Чтобы обучать модель с 4 миллиардами параметров на 11 ГБ видеопамяти:

* **Квантование NF4**: Сжатие модели до 4 бит, что позволяет ей занимать ~5-6 ГБ вместо 16 ГБ.
* **Gradient Accumulation**: Модель учится маленькими порциями, но обновляет веса реже, что экономит память без потери качества.

## 🚀 Инструкция: Как запустить проект самостоятельно

### Шаг 1: Активация среды

Открой PowerShell в папке проекта и введи:

```powershell
.\gemma_fix_env\Scripts\activate

```

### Шаг 2: Обновление данных (опционально)

Если ты хочешь, чтобы двойник узнал что-то новое, добавь строки в `dataset.jsonl`.

### Шаг 3: Запуск обучения

Для обучения **Gemma 3 4B** выполни:

```bash
python train.py

```

**На что смотреть:**

* **Loss**: Если падает (например, с 8.0 до 0.2) — всё идет отлично.
* **VRAM**: В Диспетчере задач "Выделенная память" будет заполнена почти полностью (10.5 - 11 ГБ).

### Шаг 4: Общение с двойником

Запусти чат:

```bash
python chat.py

```

Скрипт подгрузит базовую модель от Google и твои уникальные «знания» из папки с адаптерами.

## ⚠️ Важные примечания

* **Не трогай** `torch.__version__**`: Любая попытка вручную изменить строку версии приведет к падению `bitsandbytes` с ошибкой `TypeError`.
* **Температура**: При обучении твоя карта нагревается до **75°C** и выше. Убедись, что корпус хорошо продувается.
* **Библиотеки**: Если что-то не запускается, проверь наличие `accelerate` командой `pip install accelerate`.
